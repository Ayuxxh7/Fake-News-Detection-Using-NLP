# Fake News Detection using NLP

A beginner-friendly college mini project that classifies a news headline or article as **REAL** or **FAKE** using
Natural Language Processing (NLP) and Machine Learning, with a Streamlit web interface.

**Tech stack:** Python, Pandas, NumPy, Scikit-learn, TF-IDF, Logistic Regression, Matplotlib, Streamlit.

## How to install and run

1. Install **Python 3.9 or newer** (tick "Add Python to PATH" on Windows).
2. Open a terminal inside the `Fake_News_Detection` folder.
3. (Recommended) create a virtual environment:
   ```
   python -m venv venv
   venv\Scripts\activate          # Windows
   source venv/bin/activate       # Mac / Linux
   ```
4. Install the libraries:
   ```
   pip install -r requirements.txt
   ```
5. **Train the model on your computer** (takes a few seconds):
   ```
   python train_model.py
   ```
   This prints Accuracy, Precision, Recall, F1 and the Confusion Matrix, and saves `model/trained_model.pkl`.
   (Always retrain on your own laptop so the saved model matches your scikit-learn version.)
6. Start the web app:
   ```
   streamlit run app.py
   ```
   The browser opens at `http://localhost:8501`. Paste news text (or load a sample) and click **Predict**.

Optional: rebuild the PDF report after retraining: `python documentation/build_report.py`

## About the dataset (please read)

`dataset/news.csv` is a **small synthetic sample** (250 REAL-style + 250 FAKE-style items) generated by
`dataset/generate_sample_dataset.py` so that the project runs immediately. It is **not real-world news**.
Because of this, the scores measured on it (100% on the test split) are **not realistic** — the test items share
phrasing with the training items. Say this clearly to your teacher.

### Use a real dataset (recommended for better results)

1. Download a public dataset from Kaggle, for example:
   - "Fake and Real News Dataset" (ISOT; `Fake.csv` and `True.csv`)
   - "WELFake" dataset
   - "Fake News Detection" datasets with a `title`/`text` + label column
2. Convert it to a CSV with two columns: `text` and `label` (values `FAKE` / `REAL`; `0` / `1` also work).
   For ISOT: add `label = FAKE` to `Fake.csv`, `label = REAL` to `True.csv`, combine them, and save as `news.csv`.
   If your file also has a `title` column, it is joined with `text` automatically.
3. Train on it:
   ```
   python train_model.py --data path/to/your_dataset.csv
   ```
   Large datasets (40,000+ rows) still run on a normal laptop but may take a minute or two.

## How it works (short)

1. **Preprocessing** (`preprocess.py`): lowercase -> remove URLs/HTML/punctuation/digits -> tokenize -> remove stopwords.
2. **TF-IDF** converts each text to numbers (unigrams + bigrams, up to 5000 features).
3. **Logistic Regression** is trained on 80% of the data and tested on the remaining 20%.
4. The vectorizer and model are saved with Joblib. The app loads them, preprocesses the user's text the same way,
   and shows REAL / FAKE plus the model score.

## About the "model score"

The percentage shown is the probability from Logistic Regression. It has **not been calibrated or verified on
real-world news**, so it is shown only as a model score with a warning, not as a guarantee. Results below 65% are
flagged as "not very sure".

## Limitations

- The model learns **words and writing style**, not facts. In testing, a false claim written in calm, official
  language was classified as REAL, so the model can be fooled.
- The sample dataset is small and synthetic; real performance on real news will be lower.
- English text only; no fact-checking or source verification.
- Old training data becomes outdated as news topics change.

## Troubleshooting

| Problem | Fix |
|---|---|
| "Trained model not found" | Run `python train_model.py` first |
| "saved model could not be loaded" | scikit-learn version differs; run `python train_model.py` again |
| `streamlit` not recognised | Run `python -m streamlit run app.py` |
| "dataset not found" | Run `python dataset/generate_sample_dataset.py` |
